Question 1 Analysis

CPU Functional Components & Main Memory Architecture

Overview of the Control Unit (CU), Arithmetic Logic Unit (ALU), CPU Registers, and Main Memory Hierarchy (RAM, ROM, Cache, Registers).

Student Badge: Muskan Bhasin (Roll No.: 1826055) "State 3 main functional components of CPU and 4 types of main memory with one key characteristic of each."

1.1 The 3 Main Functional Components of CPU

Control Unit (CU) System Conductor

1. Control Unit (CU)

Directs all operations inside the CPU by fetching instructions from main memory, decoding them into micro-operations, and issuing timing signals to control data movement between components.

🔑 Key Characteristic: Manages instruction execution flow and data routing without executing arithmetic or storing data.
Arithmetic Logic Unit Computation Engine

2. Arithmetic Logic Unit (ALU)

Performs fundamental mathematical operations (addition, subtraction, multiplication) and logical comparisons (AND, OR, NOT, greater-than, less-than) on data operands.

🔑 Key Characteristic: Performs actual data manipulations and logical evaluation required by CPU instructions.
Registers On-Chip Storage

3. CPU Registers

High-speed internal storage locations inside the processor used to hold temporary operands, immediate instruction addresses, and intermediate computation results.

🔑 Key Characteristic: Provides sub-nanosecond single-cycle access speed directly accessible by the ALU and CU.

1.2 The 4 Primary Types of Memory & Key Characteristics

1. RAM (Random Access Memory)
Primary Volatile Workspace

Temporary storage holding active operating system code, loaded user software, and dynamic runtime data.

🔑 Key Characteristic: Volatile (data lost instantly when power is turned off).
2. ROM (Read-Only Memory)
Permanent Firmware Storage

Non-volatile memory holding system boot instructions (BIOS/UEFI) and low-level hardware microcode.

🔑 Key Characteristic: Non-volatile (retains data permanently without power).
3. Cache Memory (L1/L2/L3)
High-Speed Buffer

Small, ultra-fast SRAM buffer sitting between CPU and RAM to store frequently accessed data.

🔑 Key Characteristic: Extremely low access latency (1–10 ns) bridging speed gap.
4. CPU Registers
On-Core Fast Storage

Dedicated internal cells inside the CPU execution core (PC, IR, MAR, MDR, ACC).

🔑 Key Characteristic: Fastest storage tier in architecture (0.2–0.5 ns).

Question 4 Analysis

Sequential Access vs. Direct Access Devices

Contrasting linear ribbon spooling (Magnetic Tape) with direct sector addressing (Disks & Optical Media).

Student Badge: Muskan Bhasin (Roll No.: 1826055) "Distinguish sequential access devices from direct access devices in terms of retrieval method, access time, applications and cost."
Parameter Sequential Access (e.g., Magnetic Tape) Direct Access (e.g., Magnetic Disk / Optical)
Data Retrieval Method Linear record-by-record traversal from start of ribbon ($R_1 \rightarrow R_2 \rightarrow \dots \rightarrow R_N$). Direct block/sector addressing via read/write head movement.
Access Time Variance Variable & Position-dependent (seconds to minutes). Nearly Uniform & Fast (milliseconds: Seek + Rotational Latency).
Typical Applications Bulk batch processing, cold archives, disaster recovery dumps. Online transaction processing (OLTP), active OS partitions, web servers.
Cost per GB Storage Extremely Low (~$0.005 / GB) Moderate to High (~$0.018 / GB for HDD; higher for SSD).
Question 5 Architecture

RAM (SRAM, DRAM) vs. ROM (PROM, EPROM, EEPROM)

Comparing silicon cell structures, volatility, speed, cost, and roles during boot-up vs execution.

Student Badge: Muskan Bhasin (Roll No.: 1826055) "Compare RAM (SRAM/DRAM) with ROM (PROM/EPROM/EEPROM) in terms of volatility, speed, cost, read/write, and system roles."
SRAM (Static RAM)
6T Flip-Flop

Ultra-fast (0.5–2.5 ns), zero refresh required. Used for CPU Cache (L1/L2/L3). High cost/bit.

DRAM (Dynamic RAM)
1T-1C Cell

High density, requires periodic refresh every 64ms. Used for Main System Memory. Moderate cost.

PROM
Fusible Links

One-Time Programmable (OTP). Fuses physically blown using high voltage programmer. Irreversible.

EPROM
UV Glass Window

Erasable using intense UV-C light through quartz window for 20 mins. Entire chip erased.

EEPROM / Flash
Electrical Tunneling

Electrically erased and rewritten byte-by-byte or block-by-block in-circuit. Modern BIOS/UEFI.

Assessing Tape Libraries vs RAID HDD Arrays vs Optical Discs for 20+ year record retention.

Student Verdict: Muskan Bhasin (Roll No.: 1826055) Magnetic Tape Library (LTO) is the Most Suitable Medium

Why Magnetic Tape Libraries (LTO) Win for Institutional Archiving

  • 85% TCO Savings: Media cost (~$0.005/GB) and near-zero power/cooling consumption on cold storage shelves reduce 20-year operational expenditure massively compared to spinning RAID arrays.
  • Air-Gapped Ransomware Immunity: Offline cartridges on vault shelves are physically disconnected from network cyberattacks.
  • 30+ Year Longevity: Barium Ferrite cartridges survive 30+ years in climate vaults without drive motor failure or bit rot ($10^{-19}$ BER).
Question 7 Critique

Critique of Increasing Clock Speed Alone

Analyzing why clock frequency alone fails without Cache, Word Length, Core Count, and Main RAM balance.

Student Critique: Muskan Bhasin (Roll No.: 1826055) "CPU Time = Instructions × CPI × Clock Cycle Time. Raw GHz alone causes severe thermal and memory stalls."
1. Cache Memory

Memory Wall Bridge

High clock speed stalls for 300+ cycles during RAM fetches. Large L2/L3 cache achieves 95%+ hit rates, keeping CPU busy.

2. Word Length

32-Bit vs 64-Bit Width

64-bit registers process 8 bytes per cycle and address exabytes of RAM, whereas 32-bit is capped strictly at 4 GB RAM.

3. Core Count

Thermal & Amdahl's Law

Power grows cubically ($P \propto f \cdot V^2$). Multi-core parallel execution delivers higher aggregate throughput at cool frequencies.

4. RAM Capacity

Disk Thrashing Cliff

Insufficient RAM forces virtual memory page swapping to disk (100,000x slower), reducing a 5 GHz CPU to effective kilohertz crawl.
